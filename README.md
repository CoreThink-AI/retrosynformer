# RetroSynFormer

RetroSynFormer is a decoder only decision transformer (GPT-2) for generating sequences of retrosynthetic templates, reactions (atom-aligned SMILES strings), and starting material classification tokens for a single target compound (SMILES).

Synthesis routes are generated by iteratively predicting chemical reactions from a set of reaction templates that encode known transformations, and routes are scored during construction using a novel reward function. RetroSynFormer is trained on routes extracted from the PaRoutes dataset of patented experimental routes.


# Installation

Requires Python ≥ 3.10. Clone the repo and install with [uv](https://docs.astral.sh/uv/):

```sh
# CPU-only
uv sync --extra cpu
source .venv/bin/activate

# AMD ROCm GPU (verified: torch 2.5.1+rocm6.2 on taco / Strix Halo iGPU)
uv sync --extra rocm
source .venv/bin/activate

# NVIDIA CUDA GPU
uv sync --extra cuda
source .venv/bin/activate
```

`rdchiral` must be cloned at `../rdchiral` (sibling of this repo).

1. Download the [PaRoutes dataset](https://zenodo.org/records/17177425) and place files in `data/`
2. Update paths in `results/config.yaml`
3. Train: `rs-train -c results/config.yaml`
4. Predict: `rs-predict` (or `python predict.py -d results/ -w 50`)

## Training

```sh
rs-train -c results/config.yaml          # preferred entry point
rs-hypertune -c results/config.yaml      # Optuna hyperparameter search
```

## Inference

```sh
python predict.py -d results/ -w 50      # validation set
python predict.py -d results/ -w 50 --n1 # PaRoutes N1 benchmark
python predict.py -d results/ -w 50 --n5 # PaRoutes N5 benchmark
```

## Evaluation

```sh
python src/retrosynformer/utils/evaluation.py
python src/retrosynformer/utils/evaluation_compare_aizynth.py
```
